## Distribution flavour and debug source sets

The app has a `distribution` product-flavour dimension (`full` / `foss`).
The crash-reporting implementation is the only production code that differs
between flavours; everything else lives in `main`. The `debug` source set adds
the trigger-journal dump receiver, which is why a release build has no dump
path (see `docs/static-analysis.md`).

Two files in this area are not Kotlin and so are not generated below:
`app/google-services.json` (Firebase project config at the module root,
processed by the Google Services plugin for every build except a `foss`-only
one) and `app/src/full/AndroidManifest.xml` (overlay adding the
`firebase_crashlytics_collection_enabled` /
`firebase_analytics_collection_enabled` opt-in meta-data).
