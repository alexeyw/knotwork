# One line per suppressed rule: `path :: declaration :: Rule`, for the five rules
# that measure size and complexity (LargeClass, TooManyFunctions, LongMethod,
# CyclomaticComplexMethod, LongParameterList). `:app:verifySizeSuppressions`
# (part of `check`) fails when a suppression in the sources is not listed here,
# and when a line here names one the sources no longer contain.
#

# line is not the way to get a build green: split the code instead. Every line
