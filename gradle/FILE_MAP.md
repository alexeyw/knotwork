# Directory Map: gradle

- `wrapper/` - Contains the Gradle wrapper JAR and properties file to ensure reproducible builds; the properties pin the distribution's SHA-256 (`distributionSha256Sum`).
- `gradle-daemon-jvm.properties` - Daemon JVM criteria (generated by `updateDaemonJvm`): JDK 21 of any vendor, so CI's installed JDK satisfies it and no JDK is downloaded there.
- `verification-metadata.xml` - Dependency verification: the publisher keys and checksums every resolved artifact is checked against (see `docs/static-analysis.md`).
- `verification-keyring.keys` - The armored public keys of the trusted publishers, read by dependency verification so no key server is contacted during a build.
- `libs.versions.toml` - Gradle version catalog defining dependencies, versions, and plugins in a centralized location.
- `FILE_MAP.md` - This file mapping the current directory structure.
